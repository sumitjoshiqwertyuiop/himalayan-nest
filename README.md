# Himalayan Nest – Dwarahat Homestay & Travel Guide
Frontend demonstration site for a fictional homestay in Dwarahat, Almora, Uttarakhand. Plain HTML5, CSS3 and JavaScript; no build step.

## Run locally (VS Code)
1. Open the `himalayan-nest` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` → **Open with Live Server**.

## Structure
`index.html` · `css/style.css` · `js/script.js` · `images/` · `make_images.py` (regenerates the SVG artwork)

## Technologies
HTML5 (semantic), CSS3 (custom properties, grid, flexbox, animations), vanilla JavaScript (ES6), Google Fonts (Fraunces, Nunito Sans), OpenStreetMap links.

## Concepts demonstrated
Semantic markup and ARIA basics · mobile-first responsive layout · CSS variables · data-driven DOM rendering · IntersectionObserver scroll reveal · accessible lightbox with keyboard support · `<dialog>` modal · form validation incl. date logic · reduced-motion support · separation of HTML/CSS/JS.

## Accuracy notes
The homestay, prices and contact details are fictional placeholders. Distances marked “approx.” are rough; everything else reads “to be confirmed”. Verify distances, timings and facts before presenting them as fact.

## Deploy
- **GitHub Pages:** push to a repo → Settings → Pages → deploy from `main` / root.
- **Netlify:** drag the folder onto app.netlify.com/drop, or connect the repo (no build command, publish directory `/`).
