# Images
All files are **illustrative SVG artwork** generated by `../make_images.py`; they are not photographs of real places.
To use real photos: save them here (e.g. `dunagiri.jpg`), then change `const img` in `js/script.js` and the hero path in `css/style.css`.
Use only photos you own or that are licensed (Wikimedia Commons, Unsplash, Pexels) and credit them as required.
